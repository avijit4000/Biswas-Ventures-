# Biswas Ventures Website

A responsive storefront and services website for Biswas Ventures. It features apparel and everyday goods, a shopping bag with quantity controls, an email-based order inquiry, company services, and contact links.

## Open the website

Open `index.html` in a web browser. The page is built with HTML, CSS, and JavaScript; no build step or package installation is required.

## Project files

- `index.html` — website markup, styling, product content, and shopping bag interactions.
- `image/` — supplied Biswas Ventures logo and business banner assets.

## Notes

- Product, hero, and About photos are loaded from Unsplash and require an internet connection.
- Product order inquiries open an email to `venturesbiswas@gmail.com`. Payment processing and inventory management are not connected.
- The Facebook page is linked in the footer.
